# E-commerce A/B Test: Statistical Analysis

This project uses a reproducible, synthetic e-commerce dataset to compare an old and a new checkout design. The analysis evaluates checkout speed, conversion, device effects, and order values by customer segment.

## Dataset

`ecommerce_ab_test_dataset.csv` contains 2,400 sessions: 1,200 for each design. The data is generated by `analysis.py` with NumPy's random seed set to 42, so rerunning the script recreates the dataset. The script overwrites the CSV in its current working directory.

Columns:

- `design`: `Old` or `New`
- `device`: `Mobile`, `Desktop`, or `Tablet`
- `segment`: `New`, `Returning`, or `Loyal` customer
- `checkout_time_sec`: checkout completion time in seconds
- `converted`: 1 if the session converted, otherwise 0
- `order_value_inr`: order value in INR for converted sessions; blank otherwise

## Analysis

Run the analysis with Python 3. It requires NumPy, pandas, Matplotlib, and SciPy:

```bash
python -m pip install numpy pandas matplotlib scipy
python analysis.py
```

The script performs:

- Welch's two-sample t-test and Mann-Whitney U test for checkout time
- A two-proportion chi-square test for conversion by design
- A chi-square test of independence for conversion by device
- One-way ANOVA on log-transformed order values across customer segments, with assumption checks and Tukey pairwise comparisons
- Kruskal-Wallis testing on raw order values and a normal-approximation power analysis for conversion

## Outputs

Running `analysis.py` writes the generated dataset and these analysis artifacts to the current working directory:

- `results.json`: summary statistics, test results, confidence intervals, and power estimates
- `fig1_hist_time.png` and `fig2_box_time.png`: checkout-time distributions
- `fig3_conversion.png` and `fig4_device.png`: conversion rates overall and by device
- `fig5_violin_segment.png`: order values by customer segment
- `fig6_qq.png`: raw and log-transformed order-value Q-Q plots
- `fig7_ci.png`: checkout-time mean difference and confidence interval
